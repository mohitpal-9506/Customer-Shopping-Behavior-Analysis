# Customer Shopping Behaviour Analysis

## Project Overview

This project analyzes customer shopping behaviour using
Python, Pandas, SQL, Excel and Power BI.

The objective is to identify customer purchasing patterns,
category-wise sales, payment preferences and other business
insights.

## Tools & Technologies

- Excel
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Power BI

## Dataset

The dataset contains 3,900 customer shopping records
with 18 attributes.

Major columns include:

- Customer ID
- Age
- Gender
- Item Purchased
- Category
- Purchase Amount
- Location
- Season
- Review Rating
- Subscription Status
- Payment Method
- Frequency of Purchases
